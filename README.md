# AgentMoney — AI Agent Use Cases That Make Money

Free directory of proven ways people are using AI agents to make or save money.

## What’s included

- `index.html` — Homepage with search, categories, use-case cards
- `sponsor.html` — Sponsorship page with pricing ladder
- `styles.css` — Full dark, modern design
- `data.js` — Seed data (12 real money-making use cases)
- `app.js` — Search, filtering, newsletter form

## How to go live (step-by-step)

### 1. Create free accounts (5 minutes)

1. Go to [github.com](https://github.com) → Sign up (free)
2. Go to [vercel.com](https://vercel.com) → Sign up with the same GitHub account (free)

### 2. Buy a domain (optional but recommended)

Good options to check:
- agentmoney.ai
- moneyagents.ai
- agenthustle.ai
- cashwithagents.com
- makewithagents.com
- agentcashflow.com

Buy wherever is cheapest (Namecheap, Porkbun, Cloudflare Registrar, Google Domains, etc.).  
Cost is usually $10–15/year for a .com or .ai.

### 3. Put the site on GitHub

1. On GitHub click “New repository”
2. Name it `agentmoney` (or anything)
3. Make it Public
4. Click “Create repository”
5. Upload all the files from this folder (or use GitHub Desktop / drag-and-drop)

### 4. Deploy on Vercel (2 minutes)

1. In Vercel dashboard → “Add New Project”
2. Import the GitHub repo you just created
3. Leave all settings default → Click Deploy
4. Your site will be live at something like `agentmoney.vercel.app`

### 5. Connect your domain (if you bought one)

In Vercel → Project → Settings → Domains → Add your domain.  
Follow the DNS instructions (usually just add an A or CNAME record at your registrar).

### 6. Set up payments for sponsors

1. Create a free [Stripe](https://stripe.com) account
2. Create a Payment Link for $500 (or whatever starting price you want)
3. Replace the placeholder link in `sponsor.html` with your real Stripe Payment Link
4. Redeploy (just push the change to GitHub — Vercel auto-updates)

### 7. Newsletter (next step)

Connect the form to:
- Resend.com (very developer-friendly, free tier)
- ConvertKit
- Buttondown
- Beehiiv

Or for the absolute simplest start: just collect emails in a Google Form or Notion and send manually at first.
